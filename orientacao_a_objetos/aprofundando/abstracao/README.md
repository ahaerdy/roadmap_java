## Abstração

A palavra-chave `abstract` em Java é usada para declarar uma classe ou um método que, respectivamente, não pode ser instanciado diretamente ou deve ser implementado por subclasses. Ela é uma parte fundamental do mecanismo de abstração do Java, permitindo que os desenvolvedores definam classes e métodos abstratos que servem como um modelo (blueprint) para outras classes.
