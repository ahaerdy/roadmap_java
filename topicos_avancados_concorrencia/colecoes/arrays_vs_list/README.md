# Array vs ArrayList

**Arrays** e **ArrayLists** são duas formas de armazenar coleções de elementos em Java.

Um **array** é uma sequência ordenada de elementos do mesmo tipo de dados e de **tamanho fixo**. Uma vez que você declara o seu tamanho, não é possível alterá-lo.

Por outro lado, um **ArrayList** é uma implementação de array **dinâmica e redimensionável**. Ele pode crescer ou diminuir conforme a necessidade, permitindo que você adicione ou remova elementos sem se preocupar com o tamanho inicial.
